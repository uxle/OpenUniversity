# Fonts

## App typography (no bundled webfonts)

The app shell deliberately ships **no bundled webfont files**. Typography
uses the CSS system-font stack defined in `src/styles/variables.css`
(`--ou-font-sans` / `--ou-font-mono`), so text renders instantly with zero
network requests — no FOUT, no layout shift.

Icons are Font Awesome 6 Free (solid), **self-hosted** as a build-time
subset: `fa-solid-900.min.woff2` (generated by `tools/build-icon-font.py`
from the canonical icon registry in `src/utils/icons.js`, wired through
`src/styles/vendor/fa-solid.css`). Regenerate after adding icons.

## PDF-export font subsets (generated — do not edit by hand)

The lesson-PDF exporter (`src/pdf/`) embeds two tiny TrueType subsets so
exported PDFs stay fully vector ("never pixelates") and can render
everything the lessons contain. Both are rebuilt by npm scripts whenever
content changes:

| File | Built by | Purpose |
|------|----------|---------|
| `noto-devanagari-pdf-subset.ttf` | `npm run build:pdf-fonts` | Shaped Devanagari glyphs (Type0/Identity-H). Shaping tables land in `src/pdf/data/devanagari-shaping.json`. Source: Noto Sans Devanagari (OFL). |
| `pdf-symbols-subset.ttf` | `npm run build:pdf-symbols` | Glyphs the PDF standard-14 fonts cannot show: box-drawing art (─ │ ├ …), ₹, sub/superscript digits (H₂SO₄, x⁴), ✓ ✗, arrows. Source: DejaVu Sans. |

DejaVu Sans is used under the Bitstream Vera/DejaVu license (free
redistribution and embedding permitted). Noto Sans Devanagari is used
under the SIL Open Font License. Both licenses permit embedding subsets
in generated documents; neither requires shipping the full fonts.
