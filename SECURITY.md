# Security Policy

## Reporting a Vulnerability

If you discover a security issue in OpenKnowledge (e.g. XSS through
lesson/MCQ content rendering, unsafe storage handling), please do **not**
open a public issue. Instead, report it privately to the maintainers via
the repository's private vulnerability reporting feature.

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce, or a minimal proof of concept.
- Any suggested remediation, if you have one.

## Scope

This covers the OpenKnowledge application code (`src/`, `tools/`). Issues
in the separate Zolto engine should be reported to that project directly:
https://github.com/uxle/Zolto

## Response

We aim to acknowledge reports promptly and to keep reporters updated as a
fix is developed and released.
